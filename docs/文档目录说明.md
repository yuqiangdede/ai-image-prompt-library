# docs 文档目录说明

本说明只做目录导航，不介绍或列举具体文件，也不替代知识索引 `docs/pocket/README.md` 或各主题的权威资料。

生成时间：2026-11-12。内容为初始化时的目录快照，重新初始化或新增/调整目录后可能需要更新。

| 目录（相对仓库根） | 用途 |
| --- | --- |
| `docs/agents/` | 工程 Skill 的初始化配置：Issue Tracker、triage 标签、领域文档规则、统一文档布局 |
| `docs/pocket/` | 项目知识索引；已有权威资料仍在原位置，本目录只做导航与缺失主题补位 |
| `docs/pocket/meta/` | 知识归属与维护策略；术语表（`glossary.md`）按需创建 |
| `docs/_work/` | 任务级中间产物工作区：阶段分析、Gate、评审、检查点、报告部件，缓存归各任务 `tmp/` |

未建立的分类目录（如 `docs/pocket/requirements/`、`docs/pocket/adr/`、`docs/pocket/operations/`）在首次真正需要时创建，不预建空目录；出现时请同步更新本表。

代码与素材目录（`site/`、`scripts/`、`library/`、`.github/`）的用途见根目录 [README.md](../README.md)，不在本说明内重复。

本次检查未发现因权限、安全或链接原因跳过的目录。

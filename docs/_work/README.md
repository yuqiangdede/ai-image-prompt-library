# 项目文档中间产物工作区

本目录是项目初始化登记的中间产物根目录，位置以 [`docs/agents/document-layout.md`](../agents/document-layout.md) 为准。所有 Skills 的阶段文件都放这里，不另建平行目录。

按 `<task-id>/` 保存来源提取稿、阶段分析、Gate、评审、检查点、报告组装 part 及临时缓存；缓存归 `<task-id>/tmp/`。每个任务注明来源文件/版本、阶段、状态（draft / pending / verified）和关联的正式文档。

工作稿不构成正式需求、设计或运维权威，也不替代 `docs/pocket/README.md` 指向的现有资料。敏感缓存、用户数据和令牌默认不提交；归档、迁移或删除前先确认。

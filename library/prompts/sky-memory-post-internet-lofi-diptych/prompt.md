# 蓝天记忆｜Post-Internet 低保真抽象符号海报

## 使用方式

上传一张参考照片，生成一张上下双层构图的竖版艺术海报：上半部分保留参考摄影的核心视觉，下半部分将照片内容压缩为小型抽象符号，搭配大面积留白、过时 GUI 残片与低保真像素感。参考图在本次示例中为强日光、蓝天白云与树木，封面为生成效果图。

## 用户原始提示词（完整保留）

下半部分只提取照片中最具识别性的**主体、轮廓、动作姿态、关系张力与情绪核心**，不要复制完整人物、完整场景或现实信息，而是主动压缩视觉内容，将照片中的核心感受提炼成一个具有私人收藏意味的**小型抽象符号、小小logo、低保真视觉徽记或情绪化图像标记**。重构的画面不应呈现完整叙事，而应围绕原图中的反差、态度、情绪冲突与文化暗示展开，用极少量信息建立强烈识别度，使其像一件从旧互联网废墟里挖出来、又被重新陈列和保存的街头艺术残片。

画面采用 **post-internet lo-fi conceptual art、primitive raster graphics、pixelated stencil silhouette、retro GUI aesthetic、anti-polish graphic language** 的视觉语言。通过极度减法、低分辨率边缘、强轮廓剪影、过时数字媒介感和概念并置，将照片主体转化为一种冷、旧、反叛、神秘但又高度克制的小型符号。主体不需要完整呈现真实结构，可以被压缩为粗粝黑色块面、像素化轮廓、模板式剪影或图像残影；保留最具辨识度的动作、轮廓、关系或某个关键物件，使其像一个被高度编码后的视觉标志，而不是现实对象的缩小复制。整体应保留 **semantic contrast、conceptual juxtaposition** 的逻辑，通过强硬与脆弱、冷感与情绪、攻击性与温柔、街头感与陈列感之间的微妙冲突，制造真正的记忆点。

构图以**强符号中心与大面积沉默留白**为核心。主体应以小尺度存在于下半部分之中，可被置于一个克制的方形框架、矩形边界或类似陈列标本的视觉容器中，再辅以极少量界面残片、小型符号或细微信息痕迹。整体采用“大面积空场 → 强轮廓主体 → 单一微小异常焦点 → 下方或边缘极少界面痕迹”的关系结构。主体可居中、轻微偏移或保留略笨拙的不完美间距，不追求绝对几何完美，而强调一种被刻意保留下来的生硬感、低技术感与冷静陈列感。留白不是空缺，而是沉默、疏离、时间、停顿与未完成感本身；通过极少元素形成强识别、高压缩、低信息密度却高文化密度的视觉状态。

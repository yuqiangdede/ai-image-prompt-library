# 海威新界｜照片转高端时尚杂志封面

## 使用方式

上传一张清晰的人物肖像照片作为人物参考图，复制下方提示词生成一张独立的高端时尚杂志封面。刊头固定为「海威新界」。可自行修改出版日期、版次和专题标题。

## 完整生图提示词

将上传的参考照片转换为精致的高端时尚杂志封面。让主体呈现自然放松的姿势，站在古旧的建筑石墙前。午后阳光温暖美丽，枝叶在石墙上形成自然、错落、有呼吸感的投影。整体服装气质为柔软中性色调的优雅极简主义，但**以保留参考照片中的实际服装为最高优先级，不可擅自换装**，可通过自然调色与布料质感表现来靠近这一风格。

### 人物与真实摄影

- 严格保留参考人物原始的脸型、五官比例、发型、发色、年龄感、表情、身体比例、姿势和服装；人物身份清晰可辨。
- 保持真实摄影风格、自然皮肤纹理、微妙皱纹、真实发丝与布料褶皱；不可重塑五官、过度磨皮或改变人物身份。
- 用午后自然侧光呈现柔和明暗层次，营造轻暖中性色调与真实环境光影。
- 允许替换原有背景为质感细腻的古旧石墙，并自然延展构图以适配封面，人物仍是主要视觉中心。
- 原始照片中的平台水印、版权标识、图片编号、背景杂物等不应作为新杂志封面装饰元素复刻；仅保留必要的人物信息。

### MAGAZINE DESIGN｜杂志封面排版

- 顶部大型、优雅、高对比度衬线风格中文刊头，准确写为：**「海威新界」**。作为最醒目的刊名，富有国际高级杂志气质。
- 精致、疏密有度的编辑标题围绕主体两侧排列，避开眼睛、五官与重要人物轮廓。
- 配置小型大写英文副标题、出版日期和版次详情，字号层级清楚，例如「HAIWEI XINJIE MAGAZINE」「2026.11」「VOL.012 / ISSUE 11」。
- 左下角附近安排一个优雅的手写风格签名，作为编辑设计点缀。
- 底部附近放置醒目的**两行粗体中文专题标题**，例如「面向未来的 / 工作与生活方式」，保持自然换行与良好可读性。
- 加入一个极简条形码和一个小型、装饰用途的二维码风格图形，不要暗示二维码必然可扫描。
- 文字应少而精，以规整的网格、稳定的边距、精致的中英文对齐方式形成平衡的视觉层级。所有文字均为封面的一部分，而非悬浮 UI。

### ART DIRECTION｜艺术指导

高端韩国时尚社论结合欧洲奢侈杂志美学：精致字体、自然的留白、柔和温暖的色彩、真实的阴影、优雅的文字间距、细腻的石墙纹理、专业印刷刊物的设计完成度。构图为独立竖版杂志封面，真实摄影细节清晰，杂志标题与人物和谐共存。

### 负面约束

避免过多文字、错别字、乱码、拥挤图形、廉价特效、人造滤镜、过度磨皮、明显 CGI 感、扭曲解剖结构、额外肢体、错误手部、面部身份偏移、不合理阴影、改动服饰与姿势、遮挡主体面容、复刻原始图片水印。

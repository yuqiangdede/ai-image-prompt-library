# 双图参考姿势迁移｜人物变专业摄影棚肖像

## 上传图片
- **图一（姿势参考）**：侧身人物线稿，面朝画面左侧，食指竖直贴在嘴唇前，做“嘘/保持安静”手势。仅提取头部角度、手臂位置、手势及构图。
- **图二（人物参考）**：需要保留外观的真人照片。以图二为人物身份、面部、发型、服饰和身体比例的主要依据。
- **生成效果参考**：第三张为本提示词的一次摄影棚效果示例，并非必须上传的第三张输入图。

## 可直接复制的提示词

请将**图二中的成年人物**转换为一张专业摄影棚拍摄的写实人像，**严格参考图一的姿势**。图一只控制动作姿态，图二负责人物外观，不要混淆两张参考图的用途。

### 1. 人物一致性（以图二为准）
- 尽量保留图二人物的面部轮廓、五官比例、肤色、年龄感、发色、发型、发际线、自然皮肤纹理和可辨识特征。
- 保留图二人物的服饰风格、层次与主要材料：深色旧外套、围巾及内搭，不要擅自换成礼服或现代商务套装。
- 保留人物自然的体型与胸肩腰比例；不要把图一线稿里的人体示意或夸张比例直接复制到真人身上。
- 允许合理清理画面干扰，但保留真实发丝、衣服褶皱、磨损和少量生活痕迹。

### 2. 动作复刻（以图一为准）
- 人物站立，身体基本呈侧面，**面朝画面左侧**，以自然且清晰的左向侧脸呈现。
- 头部微微前倾或自然平视，颈肩姿态松弛，肩膀与躯干构成流畅的侧面轮廓。
- 一只手抬至嘴前，**食指竖直、贴近嘴唇中部**，其余手指自然弯曲，表达“嘘，保持安静”的手势。
- 手臂、手腕、指关节与脸部没有不自然穿插；手指数量正确、姿势明确。另一只手自然置于身体侧后方。
- 如图一线稿的身体比例与图二不一致，优先保证图二真人的真实解剖比例。

### 3. 专业棚拍
- 完全移除图二原本的室外河道、其他人物、环境杂物与动作场景。
- 将人物放入**深灰至炭灰的无缝摄影棚背景**，柔和暗调渐变，画面干净、没有文字、道具或品牌标记。
- 采用大尺寸柔光箱侧前方主光，适量弱补光和轻微轮廓光，冷中性色调、暗部保留质感，真实的面部与织物光影。
- 85mm 人像镜头质感，眼部与面部清晰对焦，背景简洁虚化，高动态范围但不过度锐化。
- 竖版 **3:4** 构图，半身至大腿位置取景，姿势完整可辨识，人物占画面主体。
- 真实商业摄影质感：毛发与布料细节自然、肤质真实、没有塑料感、没有插画/CG/人体结构辅助线。

### 4. 输出限制
只输出**一张**独立的摄影棚人像。不得拼贴三张参考图，不要保留图一线稿痕迹，不要生成原场景中的第二个人物，不要出现多余肢体、畸形手指、水印或字幕。

# 杭州·西湖复古水彩旅行明信片

创作一张令人惊叹的、单独制作的旅行插画，以[杭州]为特色，捕捉其最具标志性的地标、独特的建筑、迷人的街道和美丽的氛围。

将场景呈现为一张在温暖的象牙色、仿古纹理纸上的精致传统水彩画。融合钴蓝色、深海洋蓝、温暖的金赭石色、柔和的米色和微妙的粉红色。在整个构图中加入富有表现力的水彩溅射、有机颜料晕染、细腻的墨水细节和零星的金色点缀。

## 艺术指导

- 以一个能立即辨认的地标或标志性城市景观作为主要焦点。
- 捕捉城市真实的建筑特色和独特的氛围。
- 在合适的地方添加微妙的环境细节，如盛开的枝条、复古街灯、历史建筑、船只、电车或海滨风景。
- 使用松散、艺术化的水彩笔触，带有美丽的颜料质感和自然的颜料晕染。
- 保持大量的留白，背景为优雅的暖象牙色。
- 将复杂的建筑细节与自发的水彩溅射相结合，达到艺术且精致的效果。

## 情绪与效果

梦幻、怀旧、浪漫、优雅且永恒——类似于由水彩大师绘制的高级欧洲旅行明信片。

## 重要约束

每次生成必须仅描绘一个城市，及其真实的标志性建筑和风格。避免通用的幻想建筑、写实摄影、数字 3D 效果、厚重的轮廓、边框或不必要的排版。创作出一件连贯的、博物馆品质的水彩艺术作品，采用 **4:3 的横向构图**。

# 墨染清颜 · 低眸少女｜东方水墨意境写实人像

## 一、完整生图提示词

创作一张具有东方古典美学、真人写实摄影质感、宋式清雅审美、中国传统水墨意境、自然柔光与电影级低饱和色彩的古风女性人像摄影作品。

画面呈现一位身穿水墨印花白色汉服的年轻成年东方女子，安静地站在古朴的中式庭院窗边，微微低头，双手轻轻交叠于胸腹前方。

她拥有自然蓬松的乌黑长发，面容清秀柔和，几缕细碎发丝随意垂落在脸颊两侧。身后的古旧墙面隐约可见水墨山峦与红色花枝，画面左侧伸入几枝鲜红色花朵。

整个画面清冷、自然、安静、温婉，具有不经意间捕捉到的真实人物状态，仿佛一幅中国传统水墨画中的女子走入了现实世界。

### 1. 人物面容｜清秀自然的东方美人

一位约22岁的年轻成年东亚女性，具有清秀、温婉、略带清冷感的古典东方容貌。

* 自然柔和的鹅蛋脸，面部轮廓流畅。
* 小巧精致的下巴，脸颊保留自然饱满度。
* 纤细柔和的远山眉，自然深灰黑色。
* 内敛柔美的杏眼，眼睑自然低垂。
* 鼻梁纤细挺秀，鼻尖小巧圆润。
* 嘴唇自然闭合，淡豆沙色唇妆。
* 白皙细腻的肤色，保留真实皮肤肌理与细微毛孔。
* 极淡的裸妆，眼周略带暖棕色晕染。

不使用夸张网红妆容，不刻意放大五官，不使用过度磨皮与人工塑料质感。

### 2. 发型｜自然松散的半束长发

浓密乌黑的及腰长发，发型具有自然随性的古风半束发结构。

头顶部分长发松散地向后梳理，在后脑上方轻轻束起，其余长发自然披散在背后与肩侧。

发根蓬松，头发具有真实的重量感和细密发丝纹理。

额前采用自然偏中分设计，数缕略长的碎发从额角垂落，沿着眉眼、脸颊和下颌自然延伸，部分发丝轻微遮挡脸部。

没有华丽发冠、金属发簪、珠宝或复杂头饰，仅保留朴素自然的黑色长发。

### 3. 服饰｜白衣墨染的古典汉服

人物身穿一套素雅的米白色交领宽袖汉服。

服饰具有以下特征：

* 宽松自然的古典交领结构。
* 柔软轻薄的棉麻与纱质混合面料。
* 衣领与肩部具有自然堆叠的布料褶皱。
* 宽大袖口自然垂落。
* 面料表面分布不规则的浅灰色、墨黑色水墨晕染图案。
* 墨色图案类似朦胧山峦、烟云与写意植物。
* 墨色深浅自然过渡，具有传统宣纸水墨渗透般的视觉效果。

整体服饰没有鲜艳刺绣、金色装饰、复杂纹样或现代服装元素，呈现朴素、清雅、空灵的文人审美。

### 4. 人物姿态｜低眉垂眸

人物采用自然的三分之二侧面站姿，身体朝向画面左侧，头部微微向下倾斜约20度。

面部呈现介于侧脸与四分之三侧脸之间的角度，能够清晰看到鼻梁、嘴唇、下颌以及柔和的面部轮廓。

双眼安静地望向自己的双手，不看镜头。

双手在身体前方自然靠拢，手指微微弯曲，轻柔地相互触碰，姿态放松而克制，仿佛正在整理某件细小物品。

肩膀自然下沉，没有刻意摆拍，没有夸张表情。

人物神态安静、专注、内敛，带有淡淡的古典诗意。

### 5. 环境背景｜古墙、水墨与红花

背景为一处具有岁月痕迹的古朴中式庭院或传统建筑内部。

身后是一面米灰色、浅褐色的古旧墙壁，表面具有细微斑驳肌理。

墙面隐约绘有传统中国水墨山水图案，包括朦胧的远山、墨色山石、纤细树枝以及少量朱红色花朵。

画面左侧边缘伸入一枝真实的红色花卉，带有少量深绿色叶片和含苞待放的红色花蕾。

部分红花靠近镜头，形成自然柔和的前景虚化。

背景不出现复杂家具、现代建筑、明显文字、书法题字或其他抢夺人物视觉焦点的元素。

### 6. 光影｜阴天窗边自然柔光

采用从画面左侧进入的柔和漫射自然光，类似阴天时古建筑窗边的自然照明。

光线轻柔地照亮人物的额头、鼻梁、脸颊、嘴唇以及白色衣袖。

面部明暗过渡细腻自然，另一侧脸颊与头发保留适度阴影。

黑色长发具有细微而真实的柔和反光，避免明显的人工轮廓光。

整体曝光略偏暗，亮部柔和，暗部保留丰富层次。

没有强烈阳光、夸张逆光、影棚闪光灯、过度辉光或高反差电影特效。

### 7. 摄影构图｜沉浸式古风半身肖像

采用竖版 3:4 画幅，中近景半身人像构图。

人物位于画面中央偏右，占据画面约85%的高度。

头顶保留少量环境空间，画面下方裁切至腰腹附近，双手完整或大部分入画。

人物面部位于画面中上部，左侧保留红色花枝与自然环境留白。

镜头与人物面部高度基本持平，轻微俯视，采用自然的人像摄影透视，避免广角畸变。

模拟85mm人像镜头、f/2.8光圈的摄影效果。

焦点集中在人物眼睛、鼻梁与脸部皮肤，头发、衣物和双手保留自然细节，背景形成适度浅景深。

# 战场突击｜单张战场照片生成九宫格铅笔分镜

## 使用方式
上传一张战场剧照、摄影作品或动作场景参考图，然后复制以下提示词。画面中的人物、装备、动作与环境优先以上传图片为准；将单帧拓展为时间连贯的电影分镜，不要仅重复九遍同一构图。

## 可直接复制的提示词

你是一名专业电影分镜师与手绘概念艺术家。

请以我上传的**战场突击参考照片**为核心，绘制**一整页由九个独立镜头组成的电影分镜头脚本**，使用 **3 列 × 3 行**的整齐网格排版。所有镜头要围绕同一段连续的战场突击过程展开，忠实保留参考图中士兵的钢盔、旧军服、背带和装备、爆炸火光、硝烟、飞扬的泥土、破损树木等关键视觉元素。

### 画面内容与镜头推进
1. **01｜远景 / 建立环境**：硝烟笼罩的战场全貌，火光、断木与散落杂物，展示危险环境。
2. **02｜中景 / 队伍推进**：多名士兵向前冲锋，主体人物位于画面中心，低机位表现紧迫感。
3. **03｜特写 / 主角**：钢盔下沾满烟尘的脸部，坚决、警觉的表情。
4. **04｜中近景 / 火力掩护**：侧向机位，战友俯身持枪掩护，背景硝烟翻涌。
5. **05｜近景 / 突发爆炸**：爆炸烟尘掀起，士兵本能卧倒，画面充满动态斜线。
6. **06｜近景 / 再次起身**：主体撑地起身，低姿态继续准备前冲，衣装和动作保持连续。
7. **07｜跟拍 / 冲锋推进**：从背后低机位跟随队伍冲锋，使用运动方向线提示移动。
8. **08｜中景 / 占领高地**：队伍穿越焦土与障碍物，抵达前方有利位置，人物动作有层次。
9. **09｜结尾 / 余韵**：主角微微仰头望向远方，烟雾仍在飘散，以面部特写收束紧张节奏。

### 绘画与排版要求
- 整体为**黑白石墨铅笔草图**，保留可见的铅笔线条、交叉排线、擦拭痕迹、细腻明暗与素描纸肌理；不是滤镜处理后的摄影照片。
- 版式像真实电影制作团队的分镜头脚本：九格画面边框清楚，每格上方标注 **镜头编号、景别、名称、建议时长**，下方用小字注明机位、运镜和动作说明。
- 在适当位置添加少量手绘运动箭头、方向线，标注应当清晰、克制，不遮挡重要画面。
- 镜头语言丰富：远景、中景、特写、低机位、侧拍、跟拍和稳定位交错；主体人物的外貌、服装与装备跨镜头保持一致。
- 保持战争场景的戏剧张力、烟火与动态，但不要添加无关的角色、现代武器、彩色装饰或科幻元素。
- 页面使用暖白色、有颗粒的素描纸作为背景，标题为「分镜头脚本（铅笔草图）」；整体**横版 3:2**，构图工整且具有概念设计师手绘的真实性。

只输出一张完整的九宫格分镜页面，不拼贴真实照片，不增加水印、品牌标志或多余边饰。

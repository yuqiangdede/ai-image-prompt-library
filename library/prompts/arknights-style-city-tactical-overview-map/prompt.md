请将我上传的【城市地图截图／卫星图／道路交通示意图】转换为一张**受《明日方舟》工业科幻美术语言启发的城市俯视战术运营地图**（top-down tactical city operations map）。这是基于真实地图结构进行的视觉再设计，不是绘制游戏关卡，也不是对原地图简单套深色滤镜。

## 一、参考地图保真
1. 以输入图像为地理构图基准，尽量保留主要河流、水域、湖泊、山地绿地、城市网格、快速路、立交、桥梁和轨道交通线路的**大致方位、连通性与相对位置**。
2. 保持纯俯视／正射地图视角，不改为等距轴测、低机位建筑插画或三维沙盘；道路、河道、城区边界在整体结构上应能与原图对应。
3. 对密集次要道路和建筑轮廓做有控制的抽象，重点保留主干交通网络、空间分区与地标识别线索，不需要逐栋建筑一比一还原。
4. 只保留从参考图中能够确认的真实地名与路线名称；无法确认的内容使用中性的区域代号，不编造地理信息、地铁站或真实道路编号。
5. 若参考图中包含现成的彩色线路，保留其主要走向和交叉关系，视觉上可以重新着色，但不能把示意线误画为精确测绘数据。

## 二、世界观与视觉风格
- 高级工业科幻／近未来城市管制中心的战术地图，借鉴《明日方舟》的克制、冷峻、模块化视觉气质，不复制游戏官方 LOGO、角色、标志性专有图标或现成界面。
- 暗灰、石墨黑、炭蓝作为底色；建筑区用层级分明的灰色矩形群组；河流用低饱和深蓝青；山体与湖周林地使用暗橄榄绿、地形等高线和隐约的高程阴影。
- 道路网络、立交与桥梁采用清晰细线；高速快速路用明亮但受控的橙色，形成城市交通骨架。
- 轨道线路、巡逻路线或行动网络可用青蓝、薄荷绿、黄色、橙红、深蓝、紫色区分；节点使用空心圆、同心圈或微型发光点，换乘节点比普通节点醒目。
- 局部加入低强度的扫描网格、十字定位线、地图角标、微小编号、剖面线纹理、斜线警戒区和淡淡雾气，营造精密的作战信息系统氛围。

## 三、构图与信息层级
- **16:9 横版，完整画幅都是地图**。城市核心密集区位于视觉中心；山地、湖泊、河流按照参考地图的大致位置展开。
- 第一视觉层：河流湖泊形态、城区密度、主要道路；第二层：多色线路与节点；第三层：小型 HUD 符号和文本标注。
- 左上角设小而克制的“OPERATIONS MAP / CITY AREA OVERVIEW”信息标题，右上角可设简洁指北针；左下角设半透明细线框图例，包含快速路、主干道、轨道线路、换乘、警戒区域等。
- 在确认名称后可设置少量地图地标标注，如城区名、河流名、湖泊名与景区名。标注统一用现代窄体无衬线字体、适度加大字距，不要覆盖主要地图结构。
- 加入少量橙红警戒斜纹区域和三角警示符号，但不得改变地形与路网；它们仅表达**虚构战术界面**，不能当作真实危险区数据。
- 如果无法由输入判断实际尺度与方位，不绘制虚假的公里比例尺或精确坐标；可以选择不显示数值比例尺。

## 四、画面质感
- 精细锐利的平面制图线条，与电影级游戏 UI 概念美术结合；图层复杂但信息关系一眼可辨。
- 建筑密度有变化，工业街区的块面结构真实而经过艺术化简化；桥梁、立交、码头、路口和水岸应细致。
- 极轻的磨损与雾霭、局部低亮度发光，不要大面积霓虹、过重的电子屏噪点、泛滥的粒子特效或赛博朋克广告招牌。
- 保留地图的可读性与地理骨架，不要把道路画成随意发散的电路板线条。
- 输出高清完整静态图片，无摄影透视、无人物、无游戏战斗格子、无水印。

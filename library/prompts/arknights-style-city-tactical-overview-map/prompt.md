# 真实城市地图 → 双风格游戏化俯视图

根据用户上传的【城市地图截图／道路交通图／卫星影像】绘制一张高质量的**正上方俯视城市地图**，而不是等距透视建筑模型。请先识别原地图的水系、山地、城区、道路、桥梁和主要地标，再根据用户指定的视觉模式重绘。

**风格模式：{{STYLE | default: 工业科幻战术地图}}**
- 模式 A：工业科幻战术地图（明日方舟式）
- 模式 B：奇幻手绘冒险地图（原神式）
- 未指定时使用 A。**只应用选定模式的美术与 UI，绝对不要把 A、B 两套视觉混在一张图里。**
- 只借鉴相应游戏的视觉语言，不复制游戏官方 LOGO、专有图标、角色、正式界面或受保护的标志性地图素材。

## 一、共通的地理骨架与视角（两个模式都适用）
1. 以输入地图的俯视结构为基准，尽量保留河流、湖泊、山脉、公园、中心城区、主干道路、高速立交、桥梁、轨道交通的**相对位置、朝向、形态和连接关系**。
2. 正射俯视，不要变成 3/4 等距视角、斜拍实景、微缩立体城市或角色战斗画面。
3. 对建筑密集区与次要街道可以艺术化简化，但不能把重要河道移位、主路随意断开、桥梁无端增加或把湖泊改成另一个形状。
4. 优先使用参考图中确实可辨认的名称；无法识别的区域可省略标签或采用明确的虚构代号。不得把艺术化补全当成真实测绘信息。
5. 地图文字以少量中文地标名称为主，层级清晰且不遮挡路网；若缺乏真实比例信息，不编造比例尺或精确坐标。

## 二、模式 A｜工业科幻战术地图
**视觉方向：**冷峻、克制、高密度、近未来工业城邦运营界面；受《明日方舟》的工业科幻美术气质启发。

- 石墨灰、炭黑、深灰蓝为主色，建筑区以明暗细微变化的细密方块表现，河流深青蓝、山地暗橄榄绿。
- 橙色高速路构成清晰交通骨架；红、黄、青、蓝、绿、紫等多色线路强调地铁、巡逻和行动网络；节点用细线空心圆与小型发光点表示。
- 呈现立交道路的分层结构、桥梁与水岸轮廓、密集城市街区，保留真实地图的可阅读性。
- 加入少量细线框、十字瞄准线、扫描网格、虚构警戒斜纹区与极轻的雾霭，不要用大面积霓虹特效淹没路网。
- 左上角放克制的英文操作图标题，角落使用小尺寸交通图例和简洁方向标；线条锐利，排版工业化，16:9 横版。
- **禁止：**彩色卡通树林、童话城堡、纸张水彩、游戏角色、关卡格子、满屏 HUD、大片赛博朋克广告。

## 三、模式 B｜奇幻手绘冒险地图
**视觉方向：**温暖明亮、细腻的二次元幻想冒险世界手绘地图；受《原神》开放世界地图的色彩、地形层次与探索氛围启发。

- 翡翠绿、草绿、青绿色山林、天蓝色湖水与河流、奶油金道路、浅砂色建筑群；色彩清澈、温暖、有阳光感。
- 用精致手绘的树冠、坡地、层叠山丘、石岸、园林、建筑屋顶与道路表现地貌；整体保持俯视，建筑细节不能破坏街区原本密度。
- 让河流和湖泊具有温柔的蓝色层次与岸线；公园、树林、山地和城市之间自然过渡；沿主要交通干线加细致柔和的金色描边。
- 点缀非常少量蓝白色菱形探索标记、传送点样式的抽象符号、精细罗盘、缥缈云气与冒险地图装饰元素，**只采用原创符号**。
- 地名使用清楚的中文字体，必要时加小型地标图形；标题不抢占地图，UI 尽量克制。
- 画面精致、丰富但不过度拥挤，像高品质游戏世界地图美术插画；推荐 16:9 横版。
- **禁止：**暗黑战术 UI、荧光警戒线、地图上站立的人物模型、巨大幻想建筑替代真实地标、过度三维透视。

## 四、输入区域特定要求
若上传的是杭州城区地图：尊重钱塘江大致走向和跨江桥梁、西湖与西湖西侧山地、上城区及各类主干路网的空间关系；不要随意改成上海地图，不得把上海城区名称写到杭州地图上。用户若提供其他城市地图，则以新参考图为准，不照搬杭州地名或布局。

## 五、输出与验收
- 仅输出一张对应当前选定模式的静态俯视地图，画面完整，无多图拼贴、无水印。
- 河流与湖泊位置可对照参考图辨认；主要道路与桥梁结构仍可读。
- 模式 A 主要价值是**工业科幻战术信息感**；模式 B 主要价值是**明快手绘探索感**。
- 地图属于艺术创作，非可用于导航、应急指挥或工程测绘的准确地理成果。

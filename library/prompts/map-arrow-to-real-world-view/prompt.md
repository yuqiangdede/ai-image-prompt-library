# 地图箭头 → 真实世界第一人称视角

## 使用方式
上传一张地图或卫星地图截图，标记观察点和朝向（红色圆圈/箭头/箭头尾为观察点，箭头尖端为视线方向），直接使用以下提示词生成一张写实地面视角图片。

## 复制提示词
你是一名地理空间场景重建师与纪实摄影师。

请将我上传的地图/卫星图截图转换为一张**站在地面、沿红色箭头方向观察**的真实世界视角写实模拟图。必须正确理解二维地图与三维透视之间的关系。

【方位与机位】
1. 优先以红色圆圈为相机位置；若没有圆圈，则以明确标出的红色箭头尾部作为观察点。以箭头尖端所指的方向作为镜头朝向。
2. 地图通常上北下南；根据道路、河流、桥梁和城市地标的相对位置还原真实视线，不能把地图的俯视角直接倾斜当作街景。
3. 摄影机离地约 1.6 米，平视，接近人眼视角，35mm 等效镜头，宽幅 16:9 构图。将可见地物正确安排在前景、中景、远景。
4. 如果观察点位于江河岸边，应从实际所在的岸边向对岸看去，前景适量保留真实尺度的岸边环境，水面占据合理比例，对岸建筑沿真实方位展开。
5. 道路、河流、岸线、桥梁、体育场馆、主要地标的左右顺序、透视关系和位置必须以参考地图为基础。

【写实要求】
- 当代城市真实建筑材料、自然光照、真实天气和空气透视，电影级但不过度艺术化的纪实摄影风格。
- 先识别地图上能够确定的地物；不能确定立面、造型、桥梁可见性或具体店招的，采取保守还原，不要凭空添加标志性建筑。
- 如有现实地标，尽量保留其真实辨识特征，不随意更换建筑形态、夸大建筑高度、缩短江面宽度。
- 不显示地图、红箭头、定位图钉、文字标注、坐标或UI。
- 画质高清，自然锐度，结构合理，无卡通、游戏建模或等距视角。

【真实性边界】
仅凭地图截图不能确定实景中的建筑立面、高程、遮挡、植被和拍摄日期，因此最终输出是**基于地图推断的写实模拟图**，不是经过街景照片或现场测绘核验的真实照片。遇到不确定细节，宁可简化，也不把想象当作实景。

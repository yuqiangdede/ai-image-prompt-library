# Hand Drawn 23｜皮影彩染

独立拆分自 [threerocks/hand-drawn-styles](https://github.com/threerocks/hand-drawn-styles) 的第 23 号画风。此 Skill 用于依据描述构造原版画风提示词，图像由用户选定的生图工具生成。

## 使用方法

1. 按下方原版配方保留完整约束，不重写或混合另一套画风。
2. 把 `【主体】`、`【主色调】`、`【文字】` 等实际出现的输入项替换成用户需求；配方本身的强调标签不是输入项。
3. 用户明确给出画幅比例时遵循用户指定；未指定时不要硬注入比例。若本画风是分镜信息图，保留原配方所需的多格结构。
4. 输出完整可直接复制的 Prompt；需要锚点的特殊画风，按后文提示使用原项目的结构化正式流程。不要将文本预览当成正式验收。

> 此画风属于上游试作版。使用完整画风配方，不自动添加原图上下对比。

## 23. 皮影彩染(shadow-puppet)

> 别名:`shadow-puppet`、`backlit-puppet`、`皮影`、`皮影彩染`。试作 v0.1，纯风格，默认不依赖原图或固定锚点。占位符 `【主体】【配色】【文字】`；无字与有限彩染有默认值。建议3:4，显式比例优先，未传时不硬锁。每张输出独立完整的皮影作品，不附原片。
>
> 先按 [内置美术指导](https://github.com/threerocks/hand-drawn-styles/blob/main/docs/image-art-direction.md) 分析主体、连接、光场与层级，默认摄影建议不能覆盖平面彩染的媒介语言。研发与试作边界见 [23号试作记录](https://github.com/threerocks/hand-drawn-styles/blob/main/docs/style-23-review.md)。

```text
创作一张独立完整的中国皮影彩染作品，画面从边到边都是同一面透光幕布上的一幕皮影演出。本次主体与动作：【主体】。画面只呈现转译后的作品，不展示原始照片、参考图、缩略原图、前后对照、上下分区、分屏、拼贴或画中画。

先在内部从主题提取三至五个识别要点：主要轮廓、最有表情的姿态、关键部件与必要的叙事接触。若提供参考材料，它仅辅助这一步，不进入最终画面。把这些要点转译成可操纵的平面偶件，不复制摄影质感，也不把题材替换成无关的古装人物。

用中国传统皮影的造型语法重新概括主体：以侧面或便于读懂轮廓的平面视角表现，外轮廓连贯有力，内部以少量云纹、几何或顺应主体结构的纹样镂刻。主体由少量有明确连接关系的片状部件组成，真正的转动处以小铆钉相连；一至两根细长竹签从画面下缘进入，连接到主体的躯干、承力部或活动肢体。竹签不是任意穿过主体的装饰线。保留刻孔之间的实体连接，形体不能被碎花纹切散。

人物与动物保留自身的体态、关节与表情姿态，不做写实面部或卡通大眼。器物、建筑、植物与风景组织成能联动的形偶或景偶：提取其最具辨识度的嘴、把手、飞檐、枝干、山脊等结构，把轮廓连成少数有主次的偶件；不要强行加人脸、人手、人腿，也不为凑关节把主体拆成互不相连的碎片。

以一幕一偶或一个紧密相连的主体组为构图中心，主体图形实际占画面面积约25%–35%，四周留出充足安静的光场；不要把这个面积误解成主体高度。主体可轻微偏心，完整轮廓与操纵关系清楚，画面讲一个动作或一个状态。必要的接触关系可以保留，但不铺满环境，不出现观众、舞台全景、厚重幕框和成套道具。主体之外只保留幕布与操纵竹签；配景或第二个物件必须由本次内容明确要求，不能自动补入衬景花木、山石、地面、杯盏或案几。器物的动作只由偶件姿态表达，不自动添加写实流体或烟汽。

整张背景是一面暖光照亮的半透明细纤维幕布，米黄或浅琥珀色光场连续统一，中心较明亮，向四周自然、缓慢暗下。幕后以一盏暖灯为主；灯具本身不入画。皮影的主要深浅来自透光、遮挡、染色与轻微离幕距离，不来自塑料高光、立体体积建模或摄影皮肤。细纸纹不抢过外轮廓，不能靠满屏噪点假装手作。

皮影是一层薄、平、半透明的彩染偶片，透过镂空处看到同一片暖幕光；有染色的实体部分也可透光，叠片处自然更深。配色方案：【配色】。从朱红、靛青、橄榄绿和琥珀黄中按主题选两至三种情绪主色，而非每次全部铺满；与暖幕统一。边框与阴影用深褐和暖墨色，不用冷硬纯黑。外缘清楚，旁边仅有短距离柔和投影虚边与轻微光晕。最多在一个运动部件上出现很轻的双影，不做全身拖影、厚重发光描边或过度虚焦。

文字要求：【文字】。默认不加文字、题字、印章、签名、水印或边框。只有明确提供准确文案时，才把一小处戏名或短句克制地放在幕布角落，不自动编造标题。

整幅视觉由皮影镂刻、平面关节、半透明彩染、暖灯幕布、柔和投影和东方留白共同成立。避免完整写实场景、照片套滤镜、普通剪纸拼贴、剪影黑块、塑料或软胶质感、3D渲染、卡通角色、密集国潮装饰、模板化海报与多图拼接。
```
